# 00 · 投喂 OpenDesign 的 brief（自包含）

> 用法：整篇作为项目 brief 传入。OpenDesign 看不到仓库，所以这篇必须能独立成立。
> 画幅、功能清单、禁止项三者缺一，生成的稿子在落地阶段必然报废。

---

## 1 产品是什么

DSH（DeepSeek Harness）是一个本地桌面 AI 编码工具。本插件 `dsh-config-manager` 是它的一个**设置面板分组**，中文名「备份与迁移」，负责四件事：备份 DSH 的配置与数据、导出成可分享的 ZIP、把别人的包导入进来、以及把配置同步到自建远端。

它不是网站，不是落地页，不是营销页。它是**一个设置弹窗里的操作面板**，用户是开发者，一次会用 30 秒到 3 分钟，目的是「备份 / 迁移 / 排错」，不是浏览。

## 2 画布（硬性）

- **固定 564 × 720 px**（宿主设置弹窗 800×800，减去左侧导航 188px 与内边距后的真实可用区）。
- 不响应式、不横向滚动、不出现多列栅格之外的横向溢出。
- 内容短时**不许**把卡片拉伸填满 → 底部会留 >40px 纯空带，读者会以为「还没加载完」。
- 内容长时**在内层滚动**（列表自身滚），不是整页变长。

## 3 视觉基调

高密度开发者工具。参考系是 Linear / Raycast / VS Code 的设置面板：信息密、层级靠字重与 1px 分割线、颜色只用来标状态。

**明确不要**：
- 营销文案（「让一切更简单」这类）
- 大圆角大卡片堆叠、大留白、渐变、发光、玻璃拟态
- 装饰性图标（图标只在能点的时候出现，或表达状态）
- 值为 0 或未知时显示成「0」的 KPI 卡
- 每个区块都加副标题解释自己

## 4 首页必须有的东西（一个都不能少）

页面 id `home`，标题「备份与迁移」。自上而下四块，**顺序有意义**（出错信息必须排在健康状态之前，否则绿色的「一切正常」是假的）：

1. **读取失败横幅**（条件出现）：说明失败原因 + 一个「重试」按钮。若失败原因是「访问方式不对」，不给重试，给原因与改法。
2. **状态条**（一条横向的细条，不是卡片）：最左一颗健康点 + 一句健康结论；右侧 3–4 个**可点击的指标段**，每段是「名词 + 数值（+ 可选的补充值）」。指标四段固定：备份（份数 + 最近时间）、快照（份数）、定时备份（开关 + 下次时间）、同步（状态 + 设备名）。数据没到时该段显示骨架条（宽度不变），不显示 0。
3. **动作工具栏**：4 个按钮 —— 「立即备份」（唯一主按钮，最左）、「导出 ZIP」、「导入」、「从外部来源导入」。
4. **最近活动卡**：标题「最近活动」+ 四列表格（时间 / 事件 / 详情 / 结果），行高紧凑，最多 8 行可视，超出在卡内滚动；结果列成功用绿点+文字，失败/跳过/进行中用徽章。

**首用空态**（一个备份都没有、也没导入过）：不显示活动表，改显示一块三步指引（备份 → 导出 ZIP → 导入），第一步高亮为当前步，其余为待办；**不重复放按钮**（按钮在上方工具栏已经很近）。

## 5 这次优化的目标（请按这个方向重做，而不是复刻现状）

现状问题（真机反馈与设计评审）：

- 首页四块之间靠留白分隔，纵向节奏平：状态条、工具栏、活动卡看起来像三张同权重的卡。
- 状态条信息被「条」的形式压平：健康结论与四个指标视觉权重相同，扫视时抓不到重点。
- 活动表是首页最大的块，但表头文案与行内信息有重复（事件列与详情列都是「Import」）。
- 底部空带：数据少时页面塌成半屏。
- 强调色用得散：多个按钮都接近主色，一屏没有焦点。

允许的做法：合并区块、重排顺序（除第 1 块必须在状态条之前）、换掉「卡」的形态（例如状态条变成一条数据带、活动表行内联成时间轴）、引入新的分组方式。
不允许的：删掉任一功能入口；把表格改成卡片瀑布（这是桌面工具，表格更好扫）；把「立即备份」降级成次要按钮。

## 6 你要交付什么

**一张 564×720 的静态 HTML**（单文件，内联 CSS，无 JS 交互，无网络资源），内容是上面的首页，用一个主题（深色）。

技术要求（为了后续能被顺畅地搬进 React + CSS Modules）：

- 所有颜色 / 字号 / 间距 / 圆角 / 动效**只在 `:root` 里定义为 CSS 自定义属性**，规则里只写 `var(--...)`。不要在规则里出现 `#hex` 或 `rgb()`。
- 每个语义区块外层加 `data-block="stat-strip"` 这类标记（block 名自取，但要语义化），方便后续一一对应。
- class 名用语义名（`.statStrip` / `.activityRow`），不要 `.a1` / `.box-2`。
- 不引入任何第三方 CSS 或图标字体；需要图标时用内联 SVG（16px 网格，1.5px 描边）。
- 字体：`ui-monospace, SFMono-Regular, Menlo, Consolas, monospace` 用于文件名/路径/数值；正文用系统 UI 字体栈。**禁止网络字体**。
- 字号只有 5 档可用：11 / 12 / 12.5 / 13 / 20（20 只用于一个页面级数字，可选）。
- 行高只有 2 档：1.25（标题与表格行）/ 1.5（正文段落）。

## 7 评审时会看什么

- 一屏之内，是否 3 秒内能回答「我上次备份是什么时候、用不用现在备份」。
- 每个可点元素是否一眼可辨（不许靠 hover 才知道能点）。
- 空态 / 加载 / 错误三态是否都被设计过，而不是只画了「有数据」的样子。
- 底部有没有 >40px 的纯空带。
- 强调色是否只落在「数据 + 至多一个控件」上。
