# 03 · 产物库（library）内容清单

> 事实来源：`src/client/library/LibraryPanel.tsx`（1582 行）、`ArtifactRow.tsx`、`ArtifactDetail.tsx`、`src/ui/artifact-view.ts`。

## 1 页面结构（自上而下，无标题行）

| # | 区块 | 类名 | 说明 |
| --- | --- | --- | --- |
| 1 | 来源筛选条 | `.libraryFilters` | 5 个按钮：全部 / 快照 / 备份文件 / 远端快照 / 市场；带计数 |
| 2 | 搜索输入 | `.librarySearch` | 一行 `type=search`，placeholder「搜索产物」 |
| 3 | 快照目录不可读提示 | `.actionRow` | warn 徽章 + 行内原因（不是「没有快照」） |
| 4 | 来源失败卡 | `.card` | 「N 个来源未读取」+ 重试按钮；不整页报错 |
| 5 | 列表 / 加载态 / 空态 | `.artifactList` / `.libraryListState` | **三者共用同一高度契约**：吃掉剩余高度 |
| 6 | 底栏 | `.libraryFooter` | 计数 + 加密徽章 + 信息提示 + 4 个按钮 |

**高度契约**：`#5 flex:1 1 auto` 恒吃剩余高度，`#1-#4` 与 `#6` 为 `flex:none`，列表自身内滚。空态也吃满高度 ⇒ 底栏恒贴底，页面不塌半截。

## 2 来源筛选

- 计数**只在对应来源加载成功后**显示；加载中或失败只显示来源名 —— **绝不显示 0**。
- 「全部」的计数 = 当前行总数。

## 3 行（`.artifactRow`）

折叠态一行（`.artifactRowHead`），左→右：

1. 展开箭头（`ExpandChevron`，形变动画，`reducedMotion="user"`）
2. 主信息区：`Chip` 来源标签 + 文件名（等宽栈 + **中段省略**，title 全文）/ 或格式化时间作标题
3. 元信息行：自由序列，`·` 连接（如「12.4 MB · 2026-11-06 22:14」）；某段没有就整段不出现，**不补「—」占位**
4. 徽章区：固定 / 当前 / 加密 / 不可读（`Badge`，加密有可访问说明「导入前需解锁」）
5. 动作区：第一个能力渲染成 `Button size=sm`（常态 ghost，悬停/展开时升 primary）+ 其余能力进 `⋯` 菜单

展开态（`.artifactDetailWrap` + `.artifactDetailInner`）：`kvRow` 键值对列表（label 左、值右、值可 title 全文），**零请求**本地渲染，不含变更摘要。

## 4 能力（`ArtifactCapability`，顺序即优先级）

`restore` / `import` / `pull` / `install` / `inspect` / `download` / `consult` / `pin` / `unpin` / `delete`

- 行只**冒泡**能力（`onAction(capability, row)`），弹窗由页面级持有 —— OpenDesign 画稿里可以画出弹窗形态，但要标出「这是页级 Modal，不是行内展开」。
- 加密行：`import` 的文案换成「解锁后导入」，动作仍是 import。
- `delete` 用 danger 变体；其余 ghost。
- **不做批量操作**（无多选、无全选）。
- 市场条目只有 `install` 一个动作。

## 5 状态矩阵

| 状态 | 渲染 |
| --- | --- |
| 首屏加载 | 8 行骨架，行高与 `.artifactRowHead` 对齐（一屏可见行数） |
| 有来源仍在路上且当前为空 | 同一骨架（**不下「暂无产物」的结论**） |
| 全部就绪但为空 | `Empty`：「还没有备份文件」 |
| 筛选/搜索后为空 | `Empty`：「没有匹配的产物」 |
| 单来源失败 | 顶部 warn 卡 + 重试；其余来源照常渲染 |
| 快照目录读不出 | 一行 warn 徽章 + 原因文字 |

## 6 底栏（`.libraryFooter`）

| 元素 | 条件 | 说明 |
| --- | --- | --- |
| 计数「N / M」 | 仅当筛选或搜索生效 | 无筛选时不显示（否则与筛选条「全部 16」重复） |
| 加密徽章 | 当前筛选后 `encryptedCount > 0` | 只数眼前这些 |
| 信息提示 `InfoHint` | 恒在 | 一句话解释备份文件从哪来 |
| 弹性空位 | — | 把按钮推到右端 |
| 导出（primary） | 恒在 | **本页唯一主按钮** |
| 导入 / 市场 / 发布 | 恒在 | ghost |

**不显示合计体积**：四源里只有备份文件有体积，求和会把「未知」混进「合计」。

## 8 现状问题（本次要解决的）

1. 折叠行有 5 个元素挤在一行（箭头/标签+名/元信息/徽章/动作），564px 下文件名被压得很短。
2. 筛选条 + 搜索占掉两行，列表可视行数只剩 8。
3. 展开态是键值对列表，与折叠行的元信息行有重复信息。
4. 底栏 4 个按钮里 primary 与旁边 ghost 的对比度不够，主按钮不突出。
5. 空态与加载态视觉一致（都是灰块），用户分不清「在加载」还是「真的没有」。
