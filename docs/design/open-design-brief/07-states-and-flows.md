## 2 空态（零数据）

原则：**空态不占整卡**，换成一句可执行的话 + 一个动作；表头不渲染（避免「空表 + 四条列名」的假界面）。

| 位置 | 渲染 | 不渲染 |
| --- | --- | --- |
| 首页 · 首用（无任何产物） | `overviewFirstSteps()` 三步：备份 → 导出 ZIP → 导入；第一步 current、其余 todo | 状态带指标段显示 `—`，不是 0 |
| 首页 · 最近活动空 | 单行 `Empty`：「还没有活动记录 · 备份或导入后会出现在这里」 | 表头、骨架行 |
| 产物库 · 列表空 | 居中 `Empty` + 现有筛选条件下的一句话（「这个来源下还没有产物」）+ 清筛选按钮 | 行、展开态 |
| 产物库 · 市场空 | 同上，文案换成「市场里还没有可安装的产物」 | — |
| 环境 · 无档案 | 「还没有档案 · 新建一个后可以单独启动」+ 同一行的创建入口 | 档案表头 |
| 同步 · 通道未配置 | 40px 矮态行：名称 + `未配置` + [配置] | 卡体、动作行、快照行、记录 |
| 同步 · 无记录 | 「还没有同步记录」单行 | 记录表头 |

## 3 加载态（首屏）

原则：**骨架与真实行同高**，切换时零跳动；首屏不让单一慢请求垄断骨架（只读端点带 `withTimeout` 是宿主侧约束，UI 侧只负责「慢就显示骨架，不显示 0」）。

| 位置 | 渲染 |
| --- | --- |
| 首页 · 状态带 | 健康点保持灰 `idle`；4 个指标段各铺一条 `--cm-skeleton` 骨架条（宽 32px、高 8px），值不占位 |
| 首页 · 最近活动 | 5 行骨架（与真实行同高 25px），表头照常渲染 |
| 产物库 · 列表 | 8 行骨架，行高 48；筛选行计数隐藏（不是 0） |
| 环境 · 档案列表 | 4 行骨架，行高 43；磁盘条保持空槽（`--cm-surface-2` 底，无彩色段） |
| 同步 · 通道卡 | 已确认的通道显示矮态 + `Spinner`；未确认的显示 40px 骨架行 |
| 同步 · 在途 | 动作行下方 `SyncActivityBar`（现有组件）：阶段文字 + 细进度条，按钮同时 loading |

## 4 错误态

原则：**错误留原位、可重试**；不用 Toast 承载「页面不可用」。

| 位置 | 渲染 | 关键约束 |
| --- | --- | --- |
| 首页/产物库 · 读取失败 | `ErrorBanner`（accessMode 变体）+ [重试] | 常驻到重试成功 |
| 产物库 · 某来源不可读 | 单行 warn 行：来源名 + 错误码 + 路径 mono + [重试] | 其它来源照常列表；计数不显示 |
| 产物库 · 加密未解锁 | 行内 noop：动作文案换成「解锁后导入」 | 不弹窗、不改行高 |
| 环境 · 复制未完成 | 行内 `bad` 徽章「未完成复制」+ 主操作换成 [清理] | 徽章不换行（列宽 104/96 已定） |
| 同步 · 页面级失败 | `ErrorBanner` + [重试] | 通道卡仍渲染矮态，不做「未配置」假象 |
| 同步 · 差异裁决失败 | 失败项行 `bad` 徽章 + 右侧裁决控件禁用（`—`） | 批量按钮不覆盖错误项（`isBulkDecidable`） |
| 导入 · 回滚不完整 | 报告区 `ReportView` + 「未撤销项」列表 | 文案必须逐项可指认 |

## 5 三个流程的走法

### 5.1 同步差异确认

1. 入口：通道卡 `同步`/`推送` → 预演完成 → `SyncConfirmView`
2. 顶部先给**能不能裁决**的规模：新增 / 覆盖 / 冲突 / 删除 / 错误 五类计数（错误用 `--cm-error`）
3. 批量只有两枚：全部用本地 / 全部用远端；右边一句说明「只覆盖待确认项，N 项错误不会被执行」
4. 行内裁决用两格开关，默认值 = 预演给出的建议；错误行整行禁用
5. 底部：左「导入前自动创建快照 · 失败整体回滚」，右 [取消] [确认导入 primary]

### 5.2 导入确认（ZIP / 外部来源）

1. 步进条一行到底（8 步），已过步骤暗色、当前步骤提亮，不用横向滚动
2. 摘要只放三行：来源 / 内容（含 sha256 + 大小 + 时间）/ 裁决（写入数 · 冲突处置 · 路径重映射）
3. 凭据缺失单独 warn：列出缺哪几个 key，并给出去哪补（同步页），不用红
4. 分区表：写入行正常、排除行整体降级（`--cm-text-3`），处理列写明「写入 · 远端」这类裁决结果
5. 回滚提示放主按钮上方一行，与按钮同屏可见

### 5.3 产物详情

1. 头部：产物名 mono + 来源 chip + 状态徽章 + [返回列表]
2. 元信息四行：创建 / 校验 / 保留 / 来源路径（路径 mono 且可省略中段）
3. 含分区：chip 组，只列实际包含的，不列补集
4. 能力按钮组：按 `ArtifactCapability` 顺序渲染可用的，首个用 primary；本行放不下就整枚移到 `⋯`
5. 同源产物：只列同来源同类型，不混类型
6. 危险操作单独一行置底，红字 ghost，不与其它按钮同组
