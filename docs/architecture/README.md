## 加一条

- 新模块级文档：`<主题>.md`，kebab-case，一个主题一份；在本表加一行。
- 只想讲某个取舍为什么这么定 → 不进这里，写 `docs/adr/`；只有真机证据与量化数据 → `docs/evidence/`。
- 对外可见的格式/协议 → `docs/contracts/`，这里只链接，不复制契约正文。

## 不变量

- 本区文档不写成教程或待办；写法是「现在的形状 + 边界 + 改哪里会炸」。
- 引用代码位置写成 路径:行号（真实路径才加反引号；行号漂移时顺手修，`check-doc-paths` 会抓失效路径）。
