CLI 救援工具
npm install -g dsh-config-manager@latest --omit=peer
dsh-config-manager help 列出全部 CLI 命令与用法（离线可用）
dsh-config-manager snapshots 列出本机回滚快照（无需 DSH 运行）
dsh-config-manager restore [--id <id>] [--dry-run] 恢复到导入前状态（离线）
dsh-config-manager reinstall [--yes] [--wipe-config] 一键重装 DSH（救援）
访问范围

本面板只接受两种来源：本机回环地址（127.0.0.1 / localhost），或宿主已信任的地址与已登录的 dsh web 会话。

用 dsh web --host <局域网地址> 启动后从别的机器打开时，页面能加载但读不到本机数据——改用 ssh -L 3080:127.0.0.1:3080 隧道从 localhost 打开即可。

CLI 与 agent 工具不受此限制。
