# BASE 统一视觉规范（所有 Stitch 屏共用）

画布 564×720（宿主设置弹窗 800×800 内，宿主左侧导航 188px 不属于本插件）。只画插件内容区这一块 564×720 的完整界面。

颜色（真实 DSH 亮色 token）：文字主 #0F1115，次 #61666B，弱 #81858C；面 #FFFFFF；分隔线 #0000001A（0.5px 控件描边 / 1px 卡片描边）；强调色 #4176E6；成功 #22C55E；警告 #F59E0B；危险 #EC1313；主按钮填充 #0F1115（hover #43454A）；ghost 激活底 #EBEEF2、激活描边 #979DA6；遮罩 #0000003D。

字号只有 4 档：11 / 12 / 12.5 / 13px；行高 1.25 或 1.5。间距只有 9 档：2/4/6/8/10/12/14/16/24px。圆角只有 4/8/12/16/999。图标只用 lucide 线性图标，14px（少数 12px）。

外壳固定三段：顶部导航条（页签：首页 / 产物库 / 同步 / 环境，右端 4 个图标按钮：⌘K、活动、历史、关于）；中间内容区；底部状态栏（左侧状态点 + 文案，右侧「v0.8.0 · DSH 2.4」）。

禁止：不要加左侧栏、不要加品牌块、不要加底部文档/终端/导出按钮、不要用渐变或阴影装饰、不要第二套字体、不要圆角超过 16px。中文文案，标点用中文全角。


## 1 页面身份
插件内弹窗 D-05「查看 / 对比」（Modal 宽版），从产物库某备份文件行的「查看与对比」动作打开，只读展示备份内容与差异预览。弹窗 540×620，画布内居中，圆角 12，白底 #FFFFFF，1px 描边 #0000001A；遮罩 #0000003D 盖满 564×720，遮罩下层是被压暗的「产物库」页（灰阶：导航「产物库」激活、搜索框 + 来源筛选、几行产物列表、状态栏「就绪 · 校验无冲突」）。
**注意：本弹窗没有底部动作区**（源码只有标题区关闭 ✕，没有 Modal.Footer），内容区一直延伸到弹窗底边并被裁切。

## 2 布局与栅格
弹窗两段：标题区 48px（标题 13px/600 + 右端 ✕ 14px，无 ⓘ）；内容区占剩余高度（内边距 12px 16px，右侧 gutter 8px，纵向可滚动，底边直接裁切内容）。
内容区顺序：文件名提示行（12px #61666B，高 20px）→ 10px → 分组 1（表头 + 徽章行）→ 14px → 分组 2（表头 + 徽章行 + 一行警示文字）→ 14px → 分组 3（表头 + 5 个子分组，每个子分组 = 子标题行 + 列表）。分组表头 = 12.5px/600 小节名；徽章高 20px、11px 字、圆角 999、浅底同色字（蓝 #4176E6 / 绿 #22C55E / 橙 #F59E0B / 红 #EC1313 的 12% 混色底）。子分组 = 子标题 12px/600（带计数徽章）+ 3 行列表（每行 12px，前置 3px 圆点，行高 22px）。

## 3 组件清单（文案逐字）
- 标题：「查看 / 对比」；右端 ✕。
- 文件名提示：「dsh-config-2026-11-08.zip」
- 分组 1 表头「包含的分区」；徽章六枚（蓝）：设置: 6、插件清单: 4、MCP 服务器: 3、提示词: 2、技能: 5、工作区: 1
- 分组 2 表头「与此备份的差异（只读预览）」；徽章五枚：蓝「将变更 12 项」、绿「已一致跳过 31 项」、红「冲突 2」、橙「密钥待补录 2」、橙「路径映射 1」；下面一行 11px 警示文字（橙 #F59E0B）：「插件 / MCP 变更将在重启 DSH 后生效。」
- 分组 3 表头「变更明细」；五个子分组，每个子标题 + 计数徽章 + 列表：
  1. 子标题「冲突（需决策）」徽章 2：列表「settings: 本机与快照都改过 theme 字段」「mcp: 同名服务器的端点不一致」
  2. 子标题「变更（将写入）」徽章 12：列表「settings: 3 个键将更新」「prompts: 新增 2 个提示词」「skills: 1 个技能版本变更」
  3. 子标题「路径映射（需处理）」徽章 1：列表「workspaces: /Users/tianyi → C:\\Users\\yzbtdmz1」
  4. 子标题「已一致（无需处理）」徽章 31：列表「sessions: 412 个会话与快照一致」（其余折叠，底部被弹窗下沿裁切）
  5. 子标题「其他」徽章 2：列表「cache: 已跳过（不参与迁移）」
- 无底部按钮区。

## 4 视觉规范
只用 BASE 的 token；字号 11 / 12 / 12.5 / 13；圆角 4/8/12/999；图标 lucide 14（✕）；无阴影无渐变；遮罩下层纯灰阶；列表行距紧凑（行高 22px），整屏信息密度高。

## 5 状态覆盖
本屏画「分析完成」态，并在同一屏内体现三种差异语义：冲突（红，需决策）、将变更（蓝，将写入）、已一致（绿，无需处理），外加橙色的密钥待补录与路径映射。
不要画加载态（SkeletonList 3 行 + 「正在分析备份内容…」）、错误 Banner、空态（「该备份无法分析（文件损坏或格式不支持）」）。

## 6 保留清单（源码逐个核对）
标题「查看 / 对比」+ ✕（backupFiles.inspect）；文件名（inspect-backup-name）；「包含的分区」六枚统计徽章；「与此备份的差异（只读预览）」五枚计数徽章 + 重启生效提示；「变更明细」五个子分组（冲突 / 变更 / 路径映射 / 已一致 / 其他）各自子标题、计数与列表项；内容区底边被裁切（表示可滚动）。

## 7 删除清单
不要底部按钮（本弹窗无动作区，只有 ✕）；不要确认框、不要「执行恢复」；不要分区勾选树、不要导出/下载入口；不要左侧栏、品牌块、底部文档/终端按钮、渐变、阴影、圆角>16。

## 8 明确禁止
不出现产品里没有的元素（饼图、环形进度、对比滑块、头像）；禁止出现底部动作区或「关闭」按钮；禁止把五个子分组漏画或合并；禁止英文界面；禁止内容区底部留大片空白（最后一个子分组应被底边裁切）。

## 9 自查验收
① 540×620 圆角 12 1px 描边居中，遮罩 #0000003D 盖满 564×720；② 三段外壳在遮罩下可辨；③ 标题「查看 / 对比」+ ✕，**没有**底栏按钮；④ 六枚分区徽章齐；⑤ 五枚差异徽章 + 橙色重启提示齐；⑥ 五个子分组齐（含计数徽章与列表）；⑦ 内容区底部有裁切、无空白；⑧ 无英文、无杜撰元素、无阴影渐变。
