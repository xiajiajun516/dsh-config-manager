# BASE 统一视觉规范（所有 Stitch 屏共用）

画布 564×720（宿主设置弹窗 800×800 内，宿主左侧导航 188px 不属于本插件）。只画插件内容区这一块 564×720 的完整界面。

颜色（真实 DSH 亮色 token）：文字主 #0F1115，次 #61666B，弱 #81858C；面 #FFFFFF；分隔线 #0000001A（0.5px 控件描边 / 1px 卡片描边）；强调色 #4176E6；成功 #22C55E；警告 #F59E0B；危险 #EC1313；主按钮填充 #0F1115（hover #43454A）；ghost 激活底 #EBEEF2、激活描边 #979DA6；遮罩 #0000003D。

字号只有 4 档：11 / 12 / 12.5 / 13px；行高 1.25 或 1.5。间距只有 9 档：2/4/6/8/10/12/14/16/24px。圆角只有 4/8/12/16/999。图标只用 lucide 线性图标，14px（少数 12px）。

外壳固定三段：顶部导航条（页签：首页 / 产物库 / 同步 / 环境，右端 4 个图标按钮：⌘K、活动、历史、关于）；中间内容区；底部状态栏（左侧状态点 + 文案，右侧「v0.8.0 · DSH 2.4」）。

禁止：不要加左侧栏、不要加品牌块、不要加底部文档/终端/导出按钮、不要用渐变或阴影装饰、不要第二套字体、不要圆角超过 16px。中文文案，标点用中文全角。

【页面身份】「环境」页的「档案」子视图（564×720）：管理 DSH profile（启动/复制/删除/新建），回答「我现在跑的是哪个档案、还有哪些档案」。环境页顶部有 Segmented 两档：档案（选中）/ 维护与诊断。
【布局与栅格】自上而下——
1) 分区标题「环境」12.5px + Segmented（两档，高 28px，选中档底 #EBEEF2 + 0.5px 描边 #979DA6 + 圆角 8px）。
2) 「档案」小节标题 12.5px + info 图标。
3) 新建档案卡（1px 描边、圆角 8px、内边距 12px）：一行——输入框（占位「档案名，如 work」，flex 1）+ 模板下拉（文案「desktop — dsh-config-manager」，宽 220）+ primary 小按钮「创建」。
4) 列表标题行：「档案列表」12px + info + 右端 11px 次色「3 个档案」+ ghost 小按钮「刷新」。
5) 档案行（每行 1px 描边、圆角 8px、行内边距 10px、行高约 64px，行间距 6px），共 3 行：
   · default：mono 名称 12.5px + 徽章「当前」（ok 绿）+ 徽章「desktop」（info）+ meta 行 11px 弱色「DSH 2.4.19 · 会话格式 v3 · 12 个 bundle」；右端三颗 ghost 小按钮「启动」「复制」「删除」。
   · work：mono 名称 + 徽章「在运行 :3281」（info）+ 徽章「自定义」+ meta 行；右端「启动」（禁用态：底 #EBEEF2 文字 #81858C）「复制」「删除」。
   · backup-2026-11：mono 名称 + 徽章「未完成的副本」（warn 琥珀）+ meta 行「复制自 work · 11-09 14:20」；右端只有「删除」一颗按钮。
6) 底部内缩状态栏：左绿点「就绪 · 3 个档案」，右「v0.8.0 · DSH 2.4」。
【组件清单】Segmented 2 档；新建卡（输入 + 下拉 + 创建）；列表标题行（info + 计数 + 刷新）；3 个档案行（名称/徽章/meta/动作）；状态栏。
【状态覆盖】画「已加载、current=default、work 在运行、一条残留副本」的默认态。加载/空/错误不画。
【保留清单】环境标题 / Segmented 两档 / 档案小节标题 + info / 档案名输入 / 模板下拉 / 创建按钮 / 档案列表标题 + info / 档案计数 / 刷新 / 每行 mono 名称 / 当前徽章 / 运行端口徽章 / 形态徽章 / 残留副本徽章 / meta 行（版本·会话格式·bundle 数）/ 启动 / 复制 / 删除 / 状态栏。
【删除清单】不要页面级说明长段落；不要按形态分组的标题（列表是扁平的）；不要「默认档案」按钮（DSH 没有默认档案概念）。
【明确禁止】不引入第二套视觉体系 / 新图标库 / 新 UI 库；不要卡片套卡片；不要给每行加乐器式图标堆。
【自查验收】① Segmented 在顶部且「档案」选中 ② 三个档案行徽章各不相同（当前/在运行/未完成的副本）③ 残留行只有删除一颗按钮 ④ 全屏只有「创建」一个深色主按钮 ⑤ 无底部空洞、状态栏内缩盒。
