# BASE 统一视觉规范（所有 Stitch 屏共用）

画布 564×720（宿主设置弹窗 800×800 内，宿主左侧导航 188px 不属于本插件）。只画插件内容区这一块 564×720 的完整界面。

颜色（真实 DSH 亮色 token）：文字主 #0F1115，次 #61666B，弱 #81858C；面 #FFFFFF；分隔线 #0000001A（0.5px 控件描边 / 1px 卡片描边）；强调色 #4176E6；成功 #22C55E；警告 #F59E0B；危险 #EC1313；主按钮填充 #0F1115（hover #43454A）；ghost 激活底 #EBEEF2、激活描边 #979DA6；遮罩 #0000003D。

字号只有 4 档：11 / 12 / 12.5 / 13px；行高 1.25 或 1.5。间距只有 9 档：2/4/6/8/10/12/14/16/24px。圆角只有 4/8/12/16/999。图标只用 lucide 线性图标，14px（少数 12px）。

外壳固定三段：顶部导航条（页签：首页 / 产物库 / 同步 / 环境，右端 4 个图标按钮：⌘K、活动、历史、关于）；中间内容区；底部状态栏（左侧状态点 + 文案，右侧「v0.8.0 · DSH 2.4」）。

禁止：不要加左侧栏、不要加品牌块、不要加底部文档/终端/导出按钮、不要用渐变或阴影装饰、不要第二套字体、不要圆角超过 16px。中文文案，标点用中文全角。


## 1 页面身份
插件内确认弹窗 D-09「断开同步通道配置？」（ConfirmDialog，danger），从同步页通道卡上的「断开配置」打开。画布 564×720，弹窗 520 宽、fit-content 高（约 300px）、圆角 12、白底、1px 描边，水平垂直居中；遮罩 #0000003D 盖满画布，下层是被压暗的「同步」页（灰阶：导航「同步」激活、通道卡、底部状态栏）。
**源码 ConfirmDialog 的标题行没有 ✕**（`<Modal.Header title={title} />`，关闭只靠遮罩 / Esc / 取消按钮）。

## 2 布局与栅格
三段：标题区 48px（仅标题，13px/600）；内容区（内边距 12px 16px，段间距 10px，正文与警示块）；动作区 56px（上边框 1px #0000001A，按钮右对齐，危险按钮在左、取消在右）。

## 3 组件清单（文案逐字）
- 标题「断开同步通道配置？」（无 ✕）
- 正文：「将删除「Git 私有仓库」的本机配置、已保存的凭据与自动同步开关。远端快照与本机备份不受影响；断开后可重新配置。」
- 警示 Banner（warn，橙 12% 混色底 + 三角警告图标）：「Git 通道的访问令牌会被一并删除：GitHub 登录状态随之失效，需要重新登录（不会自动恢复）。」
- 动作区：左「断开配置」（danger：#EC1313 底、白字、高 30、圆角 8）；右「取消」（ghost：白底、1px 描边、深色字）

## 4 视觉规范
只用 BASE token；字 12.5/13；行高 1.5；圆角 8/12；图标 lucide 14px 线性；无阴影无渐变；无大面积红色块、无红色描边容器；遮罩下层纯灰阶；正文与警示块间距 10px，警示块距动作区 12px。

## 5 状态覆盖
本屏画「Git 通道」危险确认（正文 + 登录失效警示同时出现，因 git 通道的令牌槽位同时承载 GitHub 登录）。
不要画非 git 通道（只有正文、无警示块）、不要画执行中 busy、不要画错误提示。

## 6 保留清单（源码逐个核对）
标题 `channel.clearConfirmTitle`；正文 `channel.clearConfirmMessage`（含「{channel}」= Git 私有仓库）；git 专属警示 `channel.clearGitSignOut`；确认 `channel.clearConfirm`=「断开配置」（danger）；取消 `common.cancel`；无 ✕。

## 7 删除清单
不要 ✕ 关闭图标；不要输入框、勾选框、「不再提示」；不要「恢复」「重试」；不要左侧栏、品牌块、底部文档终端按钮、渐变、阴影、圆角>16。

## 8 明确禁止
禁止把「断开配置」画成深色 primary 或蓝色（必须 #EC1313 danger）；禁止把它放在「取消」右侧；禁止红色边框卡片或红色底的大色块；禁止英文界面；禁止弹窗高过 360px 或正文上下留大片空白。

## 9 自查验收
① 520 宽、圆角 12、1px 描边、居中，遮罩 #0000003D 盖满 564×720；② 三段外壳在遮罩下可辨；③ 标题无 ✕；④ 正文与警示块文案逐字、警示块为橙 warn；⑤ 动作区左「断开配置」#EC1313、右「取消」ghost；⑥ 无输入框/勾选框；⑦ 无英文、无杜撰元素、无阴影渐变。
