# BASE 统一视觉规范（所有 Stitch 屏共用）

画布 564×720（宿主设置弹窗 800×800 内，宿主左侧导航 188px 不属于本插件）。只画插件内容区这一块 564×720 的完整界面。

颜色（真实 DSH 亮色 token）：文字主 #0F1115，次 #61666B，弱 #81858C；面 #FFFFFF；分隔线 #0000001A（0.5px 控件描边 / 1px 卡片描边）；强调色 #4176E6；成功 #22C55E；警告 #F59E0B；危险 #EC1313；主按钮填充 #0F1115（hover #43454A）；ghost 激活底 #EBEEF2、激活描边 #979DA6；遮罩 #0000003D。

字号只有 4 档：11 / 12 / 12.5 / 13px；行高 1.25 或 1.5。间距只有 9 档：2/4/6/8/10/12/14/16/24px。圆角只有 4/8/12/16/999。图标只用 lucide 线性图标，14px（少数 12px）。

外壳固定三段：顶部导航条（页签：首页 / 产物库 / 同步 / 环境，右端 4 个图标按钮：⌘K、活动、历史、关于）；中间内容区；底部状态栏（左侧状态点 + 文案，右侧「v0.8.0 · DSH 2.4」）。

禁止：不要加左侧栏、不要加品牌块、不要加底部文档/终端/导出按钮、不要用渐变或阴影装饰、不要第二套字体、不要圆角超过 16px。中文文案，标点用中文全角。

## 1 页面身份
D-27「版本更新」：关于页点「检查更新」发现新版本后弹出的更新弹窗（PluginUpdateDialog，不是 ConfirmDialog，长度可超一屏、正文可内滚）。本屏是弹窗屏：底层关于页 + 黑遮罩 + 居中弹窗。

## 2 布局与栅格
画布 564×720，遮罩 #0000003D 全铺。弹窗宽 540px（= min(640px, 100%)，左右各留 12px），圆角 12px，白底，1px #0000001A 描边，最大高 612px（85vh），本屏内容较高约 560px，竖直居中。内距三段：Header 上 12 左右 14；Body 上 8 左右 16 下 12（超出时内滚）；Footer 上 10 左右 16 下 14，带 0.5px #0000001A 上边框。

## 3 组件清单（文案逐字）
- Header：左标题「更新到 v0.9.0」，13px / 600 / #0F1115；右端一个 14px 线性关闭 ✕（lucide x，aria 名称「关闭」），距右 14px。
- 版本行（在 Header 之下，上间距 6、下间距 10，行内 gap 8）：弱色小字「当前版本 0.8.0」+ 14px 箭头「→」+ 强调色 13px / 600 的「0.9.0」。
- 提示条：警告 tint（#F59E0B 12% 底 + 同色 1px 描边），圆角 8px，内距 8px 10px，左侧 14px 三角警示图标，文字「未找到 v0.9.0 的发布说明，以下为最新一条发布内容。」12.5px / #0F1115。
- 发布说明正文（13px / 行高 1.5 / 块间 6px）：
  1) 小标题「v0.8.0 · 2026-11-10」，12.5px / 600 / #61666B；
  2) 加粗导语「远端删掉的插件，同步时也跟着删」；
  3) 段落「插件同步多了个默认关闭的开关，打开后远端删了什么、你这儿没改过的一并卸载，删掉的都能从当轮快照装回。」；
  4) 无序列表两项（弱色 • 前导、文字左缩进 14px）：第一项加粗「同步可以跟随远端删除插件（默认关）」后接「勾上开关后，远端删掉、你这边没改过的插件会在合并/自动同步时一起卸载，并在报告里逐项列明「已删除：包@版本」。」；第二项「被删的包会记进当轮快照，恢复快照时自动装回同一版本。」。
- 正文底部的两个链接按钮（上间距 10px，横向 gap 8px）：ghost 小按钮「在 GitHub 查看此版本」和「在 GitHub 查看全部版本」，白底、0.5px #0000001A 描边、13px，各带一个 12px 外链图标。
- Footer：右对齐 gap 8px，左边「取消」ghost，右边主按钮「立即更新」（#0F1115 实底、白字、高 28px、圆角 8px）。
- 遮罩下（压暗、只画结构）：关于页 = 顶导航 + 插件标题「Config Manager」+ 版本行「0.8.0」+ 一行按钮（检查更新 / 更新内容 / Star）+ 说明段 + 底部状态栏。

## 4 视觉规范
只用 BASE 的颜色 token、11/12/12.5/13 四档字号、九档间距、4/8/12/16/999 圆角；提示条用同色 12% tint，不用渐变与投影表达层级。

## 5 状态覆盖
本屏是 loaded 且发布说明非精确命中的态（代码里的「找不到该版本 → 回落最新一条并提示」）。不画 loading 骨架、不画「正在更新，请稍候…」、不画「更新完成」。

## 6 保留清单
标题含 v 前缀版本号；「当前版本 0.8.0 → 0.9.0」三段结构；提示条整句；正文两句真实更新说明；两个 GitHub 链接按钮；Footer 只有「取消」「立即更新」两个按钮。

## 7 删除清单
不要把「更新到 v0.9.0」写成「更新到 0.9.0」；不要出现「版本更新内容」这个标题（那是另一个弹窗）；不要「永不提示」「确认」按钮；不要 Emoji ⭐；不要进度条。

## 8 明确禁止
不要左侧栏、不要品牌块、不要底部文档/终端/导出按钮、不要渐变或投影、不要第二套字体、不要圆角 > 16px、按钮文案不要英文、不要 Material 色阶。

## 9 自查验收
1) 弹窗宽约 540px（占面板 96%），四周有留白；2) 标题「更新到 v0.9.0」+ 右上关闭 ✕；3) 版本行「当前版本 0.8.0 → 0.9.0」三段落齐全；4) 提示条是警告色 tint 圆角条、整句一致；5) 正文有加粗导语 + 两条 • 列表；6) 两个 GitHub 链接按钮在正文底部，Footer 只有「取消」「立即更新」。
