# BASE 统一视觉规范（所有 Stitch 屏共用）

画布 564×720（宿主设置弹窗 800×800 内，宿主左侧导航 188px 不属于本插件）。只画插件内容区这一块 564×720 的完整界面。

颜色（真实 DSH 亮色 token）：文字主 #0F1115，次 #61666B，弱 #81858C；面 #FFFFFF；分隔线 #0000001A（0.5px 控件描边 / 1px 卡片描边）；强调色 #4176E6；成功 #22C55E；警告 #F59E0B；危险 #EC1313；主按钮填充 #0F1115（hover #43454A）；ghost 激活底 #EBEEF2、激活描边 #979DA6；遮罩 #0000003D。

字号只有 4 档：11 / 12 / 12.5 / 13px；行高 1.25 或 1.5。间距只有 9 档：2/4/6/8/10/12/14/16/24px。圆角只有 4/8/12/16/999。图标只用 lucide 线性图标，14px（少数 12px）。

外壳固定三段：顶部导航条（页签：首页 / 产物库 / 同步 / 环境，右端 4 个图标按钮：⌘K、活动、历史、关于）；中间内容区；底部状态栏（左侧状态点 + 文案，右侧「v0.8.0 · DSH 2.4」）。

禁止：不要加左侧栏、不要加品牌块、不要加底部文档/终端/导出按钮、不要用渐变或阴影装饰、不要第二套字体、不要圆角超过 16px。中文文案，标点用中文全角。


## 1 页面身份
插件内弹窗 D-28「版本更新内容」（宽版 Modal，GitHub Releases 卡片流）。画布 564×720，弹窗 540 宽、高约 600（maxHeight 85vh）、圆角 12、白底 #FFFFFF、1px 描边 #0000001A，居中；遮罩 #0000003D 盖满画布，下层是被压暗的插件页（灰阶：顶部导航条（首页/产物库/同步/环境 + 右端 4 图标）、中间一张淡灰圆角卡片轮廓、底部状态栏「就绪 · 远程可选」与「v0.8.0 · DSH 2.4」，不出现任何仓库地址、令牌、指纹文本）。

## 2 布局与栅格
三段：标题区 48px（标题 + 最右 ✕）；内容区（内边距 12px 16px，纵向 10px 间距；卡片流，限高内滚，末尾留 12px）；底部 actionRow（上边框 1px #0000001A，左一个外链按钮、右侧一组两枚按钮）。
内容区顺序：版本卡 1 → 版本卡 2（第二张下部被 12px 内边距裁切，暗示还能继续滚）→ 末尾居中 11px 次要色「已加载全部版本记录」。

## 3 组件清单（文案逐字）
- 标题「版本更新内容」；最右 ✕
- 版本卡（1px #0000001A 描边、圆角 8、内边距 10px）：
  · 卡头一行：版本标题「v0.8.0」+ ok 徽章「最新」+ 日期「2026-11-09」+ 右端 ghost 小按钮「在 GitHub 上查看此版本 ↗」
  · 卡身三行要点（12.5px，行首 3px 主色小圆点）： 「新增：命令面板 ⌘K，21 条命令直达」「优化：同步差异确认逐项勾选」「修复：恢复计划在 Windows 短路径下的误判」
- 版本卡 2：卡头「v0.7.2」+ 日期「2026-10-21」+ 右端 ghost 小按钮「在 GitHub 上查看此版本 ↗」；卡身两行要点：「新增：备份排期与磁盘清理建议」「修复：加密容器未解锁时的错误码」
- 末尾居中 11px 次要色「已加载全部版本记录」
- 底部 actionRow：左 ghost「在 GitHub 上查看全部 Releases」；右侧组 ghost「永不提示」+ primary「确认」（#0F1115 底、白字）

## 4 视觉规范（钉死）
颜色只用：#0F1115 / #61666B / #81858C / #FFFFFF / #EBEEF2 / #0000001A / #00000029 / #4176E6 / #22C55E / #F59E0B / #EC1313 / #0000003D；徽章底一律 color-mix(in srgb, 色 12%, transparent)、描边 35%。字号只 11 / 12 / 12.5 / 13px，行高 1.5；间距 4/8/10/12/16；圆角 6/8/12/999；图标 lucide 线性 14px；无阴影无渐变。

## 5 状态覆盖
本屏画「两页已加载完、全部版本记录已到末尾」的成功态。
不要画加载骨架、不要画 error Banner + 重试、不要画「正在加载更多版本…」转圈、不要画空态「暂无发布记录」、不要画预发布徽章。

## 6 保留清单（源码逐个核对）
标题 `about.releaseNotes.title`；关闭 ✕（`common.close`）；版本标题 + `about.releaseNotes.latest`「最新」徽章 + 发布日期 + `about.releaseNotes.viewSingleOnGithub`「在 GitHub 上查看此版本」；卡身 Markdown 正文（ReleaseBody）；`about.releaseNotes.allLoaded`「已加载全部版本记录」；底部 `about.releaseNotes.viewOnGithub`「在 GitHub 上查看全部 Releases」+ `about.releaseNotes.neverShow`「永不提示」+ `about.releaseNotes.confirm`「确认」。

## 7 删除清单
不要「立即更新 / 下载 / 安装」按钮（那是 PluginUpdateDialog）；不要搜索框、标签页、版本选择器；不要统计数字（下载量、star 数）；不要左侧栏、品牌块、底部文档终端按钮、渐变、阴影、圆角>16。

## 8 明确禁止
禁止出现产品里没有的元素（头像、评分、时间轴、图表、二维码）；禁止卡片里再套卡片；禁止正文用大段长段落（要点行即可）；禁止英文界面；禁止底部出现「取消」按钮（本弹窗只有确认 / 永不提示 / 外链）。

## 9 自查验收
① 540 宽、圆角 12、1px 描边、居中，遮罩 #0000003D 盖满 564×720；② 三段外壳在遮罩下可辨且无仓库地址/令牌文本；③ 标题「版本更新内容」+ ✕；④ 两张版本卡（v0.8.0 带「最新」、v0.7.2）、各带日期与「在 GitHub 上查看此版本 ↗」；⑤ 末尾「已加载全部版本记录」；⑥ 底栏左外链、右「永不提示」+「确认」primary；⑦ 颜色只属第 4 节、字号只 11/12/12.5/13px；⑧ 无英文、无杜撰元素、无阴影渐变。
