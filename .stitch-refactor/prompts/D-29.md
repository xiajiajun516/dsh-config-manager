# BASE 统一视觉规范（所有 Stitch 屏共用）

画布 564×720（宿主设置弹窗 800×800 内，宿主左侧导航 188px 不属于本插件）。只画插件内容区这一块 564×720 的完整界面。

颜色（真实 DSH 亮色 token）：文字主 #0F1115，次 #61666B，弱 #81858C；面 #FFFFFF；分隔线 #0000001A（0.5px 控件描边 / 1px 卡片描边）；强调色 #4176E6；成功 #22C55E；警告 #F59E0B；危险 #EC1313；主按钮填充 #0F1115（hover #43454A）；ghost 激活底 #EBEEF2、激活描边 #979DA6；遮罩 #0000003D。

字号只有 4 档：11 / 12 / 12.5 / 13px；行高 1.25 或 1.5。间距只有 9 档：2/4/6/8/10/12/14/16/24px。圆角只有 4/8/12/16/999。图标只用 lucide 线性图标，14px（少数 12px）。

外壳固定三段：顶部导航条（页签：首页 / 产物库 / 同步 / 环境，右端 4 个图标按钮：⌘K、活动、历史、关于）；中间内容区；底部状态栏（左侧状态点 + 文案，右侧「v0.8.0 · DSH 2.4」）。

禁止：不要加左侧栏、不要加品牌块、不要加底部文档/终端/导出按钮、不要用渐变或阴影装饰、不要第二套字体、不要圆角超过 16px。中文文案，标点用中文全角。

按钮与次序：**照源码 DOM，不要统一假设**。ConfirmDialog 家族（common/ConfirmDialog.tsx 的 Modal.Footer 是先确认、后取消 ghost）⇒ 视觉为「确认/危险在左，取消在右」；Modal.Footer 自绘的流程面板按各自源码顺序（多数是次要在左、primary 在右）。危险操作只穿 danger 红，同一屏 primary 只出现一次。


## 1 页面身份
插件内轻度引导弹窗 D-29「喜欢 Config Manager 吗？」（ConfirmDialog 形态，首次使用满 3 天后弹一次）。画布 564×720，弹窗 520 宽、fit-content 高（约 230px）、圆角 12、白底 #FFFFFF、1px 描边 #0000001A，水平垂直居中；遮罩 #0000003D 盖满画布，下层是被压暗的插件页（灰阶：顶部导航条（首页/产物库/同步/环境 + 右端 4 图标）、一张淡灰圆角卡片轮廓、底部状态栏「就绪 · 远程可选」与「v0.8.0 · DSH 2.4」，不出现仓库地址与令牌文本）。
**源码 ConfirmDialog 的标题行没有 ✕**（`<Modal.Header title={title} />`）。

## 2 布局与栅格
三段：标题区 48px（仅标题，13px/600）；内容区（内边距 12px 16px，单段正文，行高 1.5）；动作区 56px（上边框 1px #0000001A，按钮右对齐：primary 在前、ghost 在后）。

## 3 组件清单（文案逐字）
- 标题「喜欢 Config Manager 吗？」（无 ✕）
- 正文「如果你觉得这个插件有用，欢迎到 GitHub 点个 ⭐ Star 支持一下——你的支持是持续维护的最大动力！」（12.5px，#0F1115，Ⓟ 里的 ⭐ 保留原样）
- 动作区：左「去点 Star」（primary：#0F1115 底、白字、高 30、圆角 8）；右「不再提示」（ghost：白底、1px 描边、深色字）
- 弹窗内不出现图标大图、不出现仓库 URL、不出现版本号

## 4 视觉规范（钉死）
颜色只用：#0F1115 / #61666B / #81858C / #FFFFFF / #EBEEF2 / #0000001A / #00000029 / #4176E6 / #22C55E / #F59E0B / #EC1313 / #0000003D；字号只 11 / 12 / 12.5 / 13px；间距 8/10/12；圆角 8/12；无阴影无渐变；遮罩下层纯灰阶；正文与动作区间距 12px。

## 5 状态覆盖
本屏画「首次弹出、未表态」态：标题 + 正文 + 两个按钮。
不要画「已点赞」成功态、不要画二次确认、不要画倒计时或进度条、不要画 ☑ 不再提醒复选项。

## 6 保留清单（源码逐个核对）
标题 `starPrompt.title`「喜欢 Config Manager 吗？」；正文 `starPrompt.body`；主按钮 `starPrompt.star`「去点 Star」（`ConfigManagerSection.tsx:201-212` handleStar：开仓库页 + 记 clicked）；次按钮 `starPrompt.dismiss`「不再提示」（`:215-218` handleDismiss：记 dismissed，永久不再弹）；遮罩点击只关闭不记表态（`:221-223`）。

## 7 删除清单
不要 ✕ 关闭图标；不要 ☑「不再显示」勾选框（选项本身就是「不再提示」按钮）；不要「稍后」「以后再说」等源码没有的第三按钮；不要插图、二维码、star 数；不要左侧栏、品牌块、底部文档终端按钮、渐变、阴影、圆角>16。

## 8 明确禁止
禁止把「去点 Star」画成蓝色或渐变（必须 #0F1115 实心 primary）；禁止把「不再提示」画成文字链；禁止红色语义（本弹窗无危险操作）；禁止英文界面；禁止弹窗高过 300px 或正文上下留大片空白。
