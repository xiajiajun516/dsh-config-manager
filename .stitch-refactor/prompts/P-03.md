# BASE 统一视觉规范（所有 Stitch 屏共用）

画布 564×720（宿主设置弹窗 800×800 内，宿主左侧导航 188px 不属于本插件）。只画插件内容区这一块 564×720 的完整界面。

颜色（真实 DSH 亮色 token）：文字主 #0F1115，次 #61666B，弱 #81858C；面 #FFFFFF；分隔线 #0000001A（0.5px 控件描边 / 1px 卡片描边）；强调色 #4176E6；成功 #22C55E；警告 #F59E0B；危险 #EC1313；主按钮填充 #0F1115（hover #43454A）；ghost 激活底 #EBEEF2、激活描边 #979DA6；遮罩 #0000003D。

字号只有 4 档：11 / 12 / 12.5 / 13px；行高 1.25 或 1.5。间距只有 9 档：2/4/6/8/10/12/14/16/24px。圆角只有 4/8/12/16/999。图标只用 lucide 线性图标，14px（少数 12px）。

外壳固定三段：顶部导航条（页签：首页 / 产物库 / 同步 / 环境，右端 4 个图标按钮：⌘K、活动、历史、关于）；中间内容区；底部状态栏（左侧状态点 + 文案，右侧「v0.8.0 · DSH 2.4」）。

禁止：不要加左侧栏、不要加品牌块、不要加底部文档/终端/导出按钮、不要用渐变或阴影装饰、不要第二套字体、不要圆角超过 16px。中文文案，标点用中文全角。

【页面身份】dsh-config-manager 插件「同步」页（564×720）。用户在这里配好一条同步通道、把配置推到远端或拉回来，并核对最近同步结果。

【布局与栅格】自上而下：① 分区标题行「同步」12.5px + info 图标（高 24px）② 四张通道卡（1px 描边、圆角 8px、卡间距 8px，顺序 git/webdav/s3/gist）③ 同步记录卡（吃掉剩余高度、自身内滚）④ 底部内缩状态栏。
第 1 张 Git 卡已配置且展开（高约 250px）：入口行（高 44px）左 git-branch 图标 + 「Git」+ 绿色徽章「已连接」，右端 ghost 小按钮「配置」「断开」+ 向上的 chevron；折叠体（浅底 #F7F8FA、圆角 8px、内边距 10px）四行：
 · 「同步分区」12px + info + 右端「已选 9 / 12 个分区」+ ghost 小按钮「选择…」
 · 复选框「自动同步」（已勾选）+ info + 右端「上次 19:52 · 成功」
 · 动作行：左「推送」（primary 小按钮，全屏唯一深色）+「拉取」（ghost）+「查看差异」（ghost）；右端「仓库 github.com/you/dsh-config」
 · 最底 11px 弱色「远端快照请在产物库查看」+ 链接样式「去产物库 ›」
第 2/3/4 张 WebDAV / S3 / Gist 未配置矮态（每张高 56px）：只有图标 + 通道名 + 灰色徽章「未配置」+ 右端 ghost「配置」，无折叠体无 chevron。
同步记录卡：标题「同步记录」+ 计数徽章「8 条」+ 右端文字按钮「刷新」；5 行记录（行高 34px、0.5px 分隔线）：11px 弱色时间 + 通道芯片（Git 灰/WebDAV 蓝/S3 紫/Gist 绿）+ 12px 次色描述 + 右端结果（成功绿点 / 跳过中性徽章 / 已中止琥珀徽章）。
底部状态栏内缩 8px、圆角 8px、1px 描边：左绿点「就绪 · 远程可达」，右「v0.8.0 · DSH 2.4」。
【组件清单】标题 + info；四张通道卡；Git 卡内 9 个控件（配置/断开/chevron/选择…/自动同步/推送/拉取/查看差异/去产物库）；同步记录卡（标题+计数+刷新+5 行）；状态栏。
【状态覆盖】画「Git 已配置并展开、其余三条未配置」的默认态。空态/加载/错误不画，但四张卡必须恒显示。
【保留清单】同步标题+info / Git 卡 + 已连接徽章 + 配置 + 断开 + chevron / 同步分区行 + 已选计数 + 选择… / 自动同步复选框 + info / 上次同步结果 / 推送 / 拉取 / 查看差异 / 仓库地址 / 去产物库 / WebDAV 卡 + 未配置 + 配置 / S3 卡 + 未配置 + 配置 / Gist 卡 + 未配置 + 配置 / 同步记录卡 + 计数 + 刷新 / 记录的时间·通道·描述·结果 / 状态栏。
【删除清单】不要页面级「同步分区」卡、不要页面级加密卡、不要远端快照列表（只留一行指路）、不要说明性长段落。
【明确禁止】不引入第二套视觉体系 / 新图标库 / 新 UI 库；未配置卡不画折叠体；四张卡不许全部展开。
【自查验收】① 四张卡齐、三张矮态 ② 只有 Git 卡有折叠体 ③ 记录卡吃掉剩余高度、无底部空洞 ④ 全屏只有「推送」一个深色按钮 ⑤ 状态栏内缩盒。
