画布 564×720（宿主设置弹窗 800×800 内，宿主左侧导航 188px 不属于本插件）。只画插件内容区这一块 564×720 的完整界面。

颜色（真实 DSH 亮色 token）：文字主 #0F1115，次 #61666B，弱 #81858C；面 #FFFFFF；分隔线 #0000001A（0.5px 控件描边 / 1px 卡片描边）；强调色 #4176E6；成功 #22C55E；警告 #F59E0B；危险 #EC1313；主按钮填充 #0F1115（hover #43454A）；ghost 激活底 #EBEEF2、激活描边 #979DA6；遮罩 #0000003D。

字号只有 4 档：11 / 12 / 12.5 / 13px；行高 1.25 或 1.5。间距只有 9 档：2/4/6/8/10/12/14/16/24px。圆角只有 4/8/12/16/999。图标只用 lucide 线性图标，14px（少数 12px）。

禁止：不要加左侧栏、不要加品牌块、不要加底部文档/终端/导出按钮、不要用渐变或阴影装饰、不要第二套字体、不要圆角超过 16px。中文文案，标点用中文全角。

## 本屏：T-03 从其它 agent 导入

### 1 页面身份
设置弹窗内「配置管理器」插件的**流程面板**：用户从首页「从其它 agent 导入」进入，先看清本机装了哪些外部 agent、能搬什么，再交给既有导入向导。本屏没有步进器（不是九步向导的一步），是一个「检测 → 选择 → 产包」的单页。
外壳三段：顶部导航条（纯文字页签 首页 / 产物库 / 同步 / 环境，激活「首页」带下划线；右端 4 个图标 ⌘K、活动、历史、关于）→ 流程面板 → 底部状态栏（左「● 就绪 · 已检测 4 个来源」，右「v0.8.0 · DSH 2.4」）。
面板头 44px：「← 返回首页」ghost 小按钮 + 标题「从其它 agent 导入」。

### 2 布局与栅格
内容区宽 564，左右内边距 16，单列，块间距 12，整页不允许出现滚动条外溢。
① 面板头 44px；
② 标题行「从其它 agent 导入」13px 加粗 + ⓘ；其下说明行 12px 次色、两行，文案逐字「读取本机已装的其它 agent 配置，先看清将导入什么，再交给既有的导入向导（分析只读，零写入）。」；
③ 来源列表**不是一张裁切容器，而是四行各自成卡**：每行一张白卡（1px #0000001A 描边、圆角 8、高 52、内边距 0 12、行间 8），四行依次纵向排列、互不裁切、外层不再套容器；每行内容：
   · 左：来源显示名 13px 主色；
   · 名右侧 6px 处一枚状态徽章：「已检测到」（成功色）或「未检测到」（info 色）；
   · 第二行 11px 次色等宽字体：「命中路径：~/.claude/settings.json · ~/.claude/CLAUDE.md」；未检测到的行写「没有命中任何真值表路径」；
   四行：① Claude Code · 已检测到（选中态）；② Cursor · 已检测到；③ Codex CLI · 已检测到；④ Gemini CLI · 未检测到（整行置灰 #81858C、不可点）。
   **选中态**：该行左侧 2px 强调色 #4176E6 竖条 + 行底 4% 强调混色，行右端一枚 14px 线性对勾图标。
④ 冲突策略脚注 11px 次色，单行：「同 id 冲突不覆盖本机内容：跳过并逐条报告」；
⑤ 「已知有损」卡（白卡，1px 描边，圆角 8，内边距 12）：11px 次色分组标签「已知有损」+ ⓘ，其下三条，每条两行：
   · 12px 主色标题「文件类分区的明文不做剥离」+ 11px 次色一行说明「技能 / 预设 / 全局指令 / 插件文件 / 会话 / 插件配置这六类分区原样进包，需要保密请先清理源文件。」

⑥ 「未迁移 3 项」卡（白卡，1px 描边，圆角 8，内边距 12）：标题行 12px 加粗「未迁移 3 项」+ 两行：

### 3 组件清单
标题行（13px 加粗 + ⓘ）、说明行、白卡容器（1px 描边/圆角 8/内部分隔线）、来源行（两行信息 + 状态徽章 + 选中竖条 + 对勾）、状态徽章（成功 / info）、等宽机器码徽章（11px、圆角 4、浅灰底）、ghost 按钮、primary 按钮。

### 4 视觉规范
完全遵循 BASE：文字 11/12/12.5/13；间距 2/4/6/8/10/12/14/16/24；圆角 4/8/12/16/999；描边 0.5px 控件、1px 卡；等宽字体只用于命中路径与机器码，正文不用第二套字体；无渐变、无阴影。

### 5 状态覆盖
本屏表达：已完成一次检测（4 个来源，3 命中 1 未命中）、已选中一个来源（Claude Code，行呈选中态）、已知有损三条都展开、未迁移项 2 条示例、产包结论已出（包含分区 + 需补录凭据 2 项）、「开始导入」可用。
不表达：加载骨架、错误横幅、空态（「未检测到任何可导入的其它 agent 配置。」）、导入进度。

### 6 保留清单（一个都不能丢）
返回、标题与说明、来源列表（显示名 + 状态徽章 + 命中路径 / 没有命中任何真值表路径）、选中态、冲突策略脚注、已知有损三条、未迁移卡与机器码、将导入的内容卡（包含分区徽章 + 需补录凭据徽章）、重新检测、开始导入。

### 7 删除清单（不得出现）
左侧来源树 / 侧边筛选；搜索框；「全选 / 反选」按钮；导入进度条；结果报告；任何弹窗；分页器；把已知有损写成三张大卡片（必须是同一张卡内的三条）。

### 8 明确禁止
不加左侧栏、品牌块、渐变阴影、第二套字体，圆角 ≤16；不出现英文长键名之外的自造概念（如「一键迁移」「智能映射」）；未检测到的来源不能出现「导入」入口；不把「已知有损」折叠成一句提示；中文标点全角，文案逐字照抄上面给出的字符串。
