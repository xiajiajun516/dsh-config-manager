# BASE 统一视觉规范（所有 Stitch 屏共用）

画布 564×720（宿主设置弹窗 800×800 内，宿主左侧导航 188px 不属于本插件）。只画插件内容区这一块 564×720 的完整界面。

颜色（真实 DSH 亮色 token）：文字主 #0F1115，次 #61666B，弱 #81858C；面 #FFFFFF；分隔线 #0000001A（0.5px 控件描边 / 1px 卡片描边）；强调色 #4176E6；成功 #22C55E；警告 #F59E0B；危险 #EC1313；主按钮填充 #0F1115（hover #43454A）；ghost 激活底 #EBEEF2、激活描边 #979DA6；遮罩 #0000003D。

字号只有 4 档：11 / 12 / 12.5 / 13px；行高 1.25 或 1.5。间距只有 9 档：2/4/6/8/10/12/14/16/24px。圆角只有 4/8/12/16/999。图标只用 lucide 线性图标，14px（少数 12px）。

外壳固定三段：顶部导航条（页签：首页 / 产物库 / 同步 / 环境，右端 4 个图标按钮：⌘K、活动、历史、关于）；中间内容区；底部状态栏（左侧状态点 + 文案，右侧「v0.8.0 · DSH 2.4」）。

禁止：不要加左侧栏、不要加品牌块、不要加底部文档/终端/导出按钮、不要用渐变或阴影装饰、不要第二套字体、不要圆角超过 16px。中文文案，标点用中文全角。

【页面身份】「同步」页上的「同步通道」配置弹窗（Git 通道，GitHub 已登录态）。弹窗浮在 #0000003D 遮罩上；遮罩下是被压暗的同步页轮廓：顶部导航条（页签「同步」为当前态）、内容区只剩一条卡片边线轮廓、底部状态栏，全部半透明可见，不新增内容。弹窗宽 541px（96%），白底，圆角 12，1px #0000001A 描边，高度贴合内容（约 470px），水平垂直居中。

【布局与栅格】弹窗内边距 16。自上而下：Header（高 40，底部 1px 分隔线，下间距 12）→ 安全提示横幅（下间距 12）→ 分组标题「仓库配置」（下间距 8）→ 仓库选择字段（下间距 10）→ 仓库地址字段（10）→ 子目录字段（10）→ 认证 token 字段（14）→ 保存行。字段结构固定：标签行（13px/1.25 #0F1115，其后 6px 处 14px info 图标 #81858C）→ 6px 后接 36px 高输入框（0.5px #0000001A 描边、圆角 8、左内边距 10、placeholder 12.5px #81858C）。

【组件清单】1) Header：左「同步通道」13px/600；紧跟 badge「Git 私有仓库」（12px，#4176E6 文字，#4176E6 14% 透明底，圆角 999，内边距 2×8）+ info 图标；右端关闭图标 ✕ 14px。2) 警告横幅：底 #F59E0B 12% 透明，圆角 8，内边距 10，文案 12px/1.5 #61666B：「安全要求：同步仓库必须为私有仓库（public 仓库会公开你的配置内容）。认证 token 仅用于仓库访问，绝不写入同步文件、提交内容或日志。」3) 分组标题「仓库配置」12px #61666B。4) 仓库选择字段：标签「从我的仓库中选择」+ info 图标；下行是同一行水平布局：Select 控件（flex 1，高 36）左文「从我的仓库中选择」12.5px #81858C、右端 chevron-down 14px，其右 8px 处 ghost 小按钮「刷新列表」12px。5) 仓库地址字段：标签「仓库地址」+ info；输入框 placeholder「https://github.com/user/private-repo.git」。6) 子目录字段：标签「仓库内子目录」+ info；输入框 placeholder「DSH备份（可选）」。7) token 字段：标签「认证 token」+ 绿 badge「凭据已配置」（12px #22C55E 文字、#22C55E 14% 底、圆角 999）+ info 图标；密码输入框 placeholder「ghp_…（可选）」；该输入框为 focus 态（0.5px #4176E6 描边）。8) 保存行：主按钮「立即保存」（#0F1115 底、白字 12.5px、圆角 8、内边距 8×14）+ 右侧 8px 处绿 badge「已保存」+ info 图标。

【视觉规范】字号只用 13 / 12.5 / 12 三档；间距只用 6/8/10/12/14/16；分隔线 1px #0000001A，控件描边 0.5px #0000001A；无阴影、无渐变；警告与成功只用对应 token 的 12%–14% 透明底。

【状态覆盖】GitHub 已登录（因此不出现登录块）；表单已保存过（保存行出现「已保存」badge）；token 输入框为空（placeholder 可见）且处于 focus；刷新列表按钮为默认 ghost 态。

【保留清单】关闭按钮、通道名 badge「Git 私有仓库」、info 图标、安全要求横幅、仓库选择下拉、刷新列表、仓库地址输入、子目录输入、token 输入、凭据已配置 badge、立即保存、已保存反馈。

【删除清单】不画「GitHub 登录」区块；不画引擎告警横幅（当前无告警）；不画弹窗 Footer；不画新建仓库内联表单与任何二级弹窗。

【明确禁止】不要左侧栏、品牌块、底部文档/终端/导出按钮；不要渐变与阴影；圆角不超过 16；不要第二套字体；不要自造文案——上面每一条提示文字必须逐字一致（含全角括号、全角句号、public 小写）；不要新增「帮助」「文档」「测试连接」「保存为默认」等源码里没有的按钮；不要画 tab、步骤条或左侧栏；不要英文标签。

【自查验收】① 遮罩下三段外壳仍可辨；② 弹窗内 6 个区段齐全、顺序与上述一致；③ 文案逐字一致，无自造句子；④ 弹窗高度贴合内容，底部不留大片空白；⑤ 色彩只出现 BASE token，无 Material 色阶。
