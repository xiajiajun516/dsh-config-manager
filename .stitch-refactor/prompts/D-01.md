# BASE 统一视觉规范（所有 Stitch 屏共用）

画布 564×720（宿主设置弹窗 800×800 内，宿主左侧导航 188px 不属于本插件）。只画插件内容区这一块 564×720 的完整界面。

颜色（真实 DSH 亮色 token）：文字主 #0F1115，次 #61666B，弱 #81858C；面 #FFFFFF；分隔线 #0000001A（0.5px 控件描边 / 1px 卡片描边）；强调色 #4176E6；成功 #22C55E；警告 #F59E0B；危险 #EC1313；主按钮填充 #0F1115（hover #43454A）；ghost 激活底 #EBEEF2、激活描边 #979DA6；遮罩 #0000003D。

字号只有 4 档：11 / 12 / 12.5 / 13px；行高 1.25 或 1.5。间距只有 9 档：2/4/6/8/10/12/14/16/24px。圆角只有 4/8/12/16/999。图标只用 lucide 线性图标，14px（少数 12px）。

外壳固定三段：顶部导航条（页签：首页 / 产物库 / 同步 / 环境，右端 4 个图标按钮：⌘K、活动、历史、关于）；中间内容区；底部状态栏（左侧状态点 + 文案，右侧「v0.8.0 · DSH 2.4」）。

禁止：不要加左侧栏、不要加品牌块、不要加底部文档/终端/导出按钮、不要用渐变或阴影装饰、不要第二套字体、不要圆角超过 16px。中文文案，标点用中文全角。

【页面身份】首页上的「定时备份」弹窗（Modal wide）。底层页面 = 首页（遮罩 24% 压暗），弹窗本体宽 560px、fit-content 高度、位于画布垂直居中偏上。
【底层页面（只画可见部分，作为背景）】顶部导航条（首页/产物库/同步/环境，首页选中 pill）+ 右端四个图标；内容区被遮罩压暗，可见状态条 4 格与动作工具栏一行按钮「立即备份（深色）/ 导出 ZIP / 导入 / 从其他 agent 导入 / 一键同步」+ 右端「活动」；下方活动表被遮罩压暗。
【弹窗本体结构 · 自上而下】
1) 弹窗头：标题「定时备份」13px 加粗 + 右端 ✕ 关闭（24px 方形 ghost）。
2) 内容区（内边距 16px）：
   a) 分组行：「定时备份设置」12px 加粗 + ⓘ；右端两颗按钮「立即备份」（ghost，带 ▶ 图标）、「保存」（primary 深色，带 ✓）。
   b) 事实网格（1px 描边、圆角 8px，两列两行）：状态「● 已开启」（绿点）| 间隔「每周一 03:00」；上次运行「成功徽章 + 2026-11-10 21:04」（mono）。
   c) 启用行：☑ 启用定时备份 + ⓘ；右端间隔下拉「每周 ▾」（宽 96）。
   d) 保留策略分组：标题「保留策略」+ ⓘ；右端 11px 次色「未启用层级时保留全部」。
   e) 三个并排数字卡（各占 1/3，1px 描边、圆角 8px、内边距 10px）：三张标题**必须不同**——「最近保留」输入 10 单位「份」；「每月保留」输入 6 单位「个月」；「每年保留」输入 2 单位「年」。数字输入框右对齐、宽 64。
   f) 底部提示行 11px 次色 + ⓘ：「仅对自动备份生效。手动导出及外部快照不受上述生命周期与清理策略影响。」
【组件清单】Modal 头、分组行 + 两按钮、事实网格、启用行 + 下拉、保留策略三卡、底部提示。
【状态覆盖】画「已开启、间隔每周、三档保留都非 0、无错误」的正常态；不要画红色错误条。
【保留清单】标题 + ✕ / 定时备份设置 + ⓘ / 立即备份 / 保存（primary）/ 状态 / 间隔 / 上次运行（徽章 + 时间）/ 启用复选框 / 间隔下拉 / 保留策略 + ⓘ + 右侧说明 / 三张数字卡（标题各不相同 + 单位 + 数字）/ 底部提示。
【删除清单】不要「执行时间窗口」之类源码没有的卡片；不要弹窗底部空白；不要在弹窗里放页面级长说明。
【明确禁止】不引入第二套视觉体系/新图标库；除「保存」外不得有第二个深色主按钮；不得把三张保留卡的标题写成同一个词。
【自查验收】① 三张保留卡标题分别是「最近保留 / 每月保留 / 每年保留」，单位分别是「份 / 个月 / 年」 ② 弹窗高度贴合内容（底部无空白）③ 底层页面工具栏能看出 5 个按钮包含「从其他 agent 导入」 ④ 只有「保存」是深色主按钮。
