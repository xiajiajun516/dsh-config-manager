# BASE 统一视觉规范（所有 Stitch 屏共用）

画布 564×720（宿主设置弹窗 800×800 内，宿主左侧导航 188px 不属于本插件）。只画插件内容区这一块 564×720 的完整界面。

颜色（真实 DSH 亮色 token）：文字主 #0F1115，次 #61666B，弱 #81858C；面 #FFFFFF；分隔线 #0000001A（0.5px 控件描边 / 1px 卡片描边）；强调色 #4176E6；成功 #22C55E；警告 #F59E0B；危险 #EC1313；主按钮填充 #0F1115（hover #43454A）；ghost 激活底 #EBEEF2、激活描边 #979DA6；遮罩 #0000003D。

字号只有 4 档：11 / 12 / 12.5 / 13px；行高 1.25 或 1.5。间距只有 9 档：2/4/6/8/10/12/14/16/24px。圆角只有 4/8/12/16/999。图标只用 lucide 线性图标，14px（少数 12px）。

外壳固定三段：顶部导航条（页签：首页 / 产物库 / 同步 / 环境，右端 4 个图标按钮：⌘K、活动、历史、关于）；中间内容区；底部状态栏（左侧状态点 + 文案，右侧「v0.8.0 · DSH 2.4」）。

禁止：不要加左侧栏、不要加品牌块、不要加底部文档/终端/导出按钮、不要用渐变或阴影装饰、不要第二套字体、不要圆角超过 16px。中文文案，标点用中文全角。

按钮与次序：**照源码 DOM，不要统一假设**。ConfirmDialog 家族（common/ConfirmDialog.tsx 的 Modal.Footer 是先确认、后取消 ghost）⇒ 视觉为「确认/危险在左，取消在右」；Modal.Footer 自绘的流程面板按各自源码顺序（多数是次要在左、primary 在右）。危险操作只穿 danger 红，同一屏 primary 只出现一次。


## 1 页面身份
插件内浮层 D-30「命令面板」（⌘/Ctrl+K 唤起的第二入口，不是居中对话框）。画布 564×720，浮层宽 420px、水平居中、距画布顶 80px、圆角 12、白底 #FFFFFF、1px 描边 #0000001A，高约 400px；遮罩 #0000003D 盖满画布，下层是被压暗的插件页（灰阶：顶部导航条（首页/产物库/同步/环境 + 右端 4 图标）、一张淡灰圆角卡片轮廓、底部状态栏「就绪 · 远程可选」与「v0.8.0 · DSH 2.4」）。

## 2 布局与栅格
单卡三段：输入区 44px（内边距 12px 14px，无边框无底色，只有底部分隔线 1px #0000001A）；列表区（内边距 4px 6px，限高 280px，超出裁剪并留出被裁切的下一行）；提示区 32px（上边框 1px #0000001A，11px 次要色居中）。
无标题行、无 ✕（Esc / 点遮罩关闭）。

## 3 组件清单（文案逐字）
- 输入框（placeholder 22px 高、无边框、13px、光标在最前）：「输入命令或搜索…」
- 分组标签「前往」（11px #81858C，左侧 6px 内缩，上下 6px）：4 行，每行 12.5px，行高 26px，首行「首页」为选中态（底色 #EBEEF2、左侧 2px #4176E6 竖条、文字 #0F1115），其余 #0F1115：首页 / 产物库 / 同步 / 环境
- 分组标签「产物库」：5 行 —— 全部 / 本机快照 / 备份文件 / 远端快照 / 市场配置（每行右侧 11px #81858C 无附注，纯标签 + 名称）
- 分组标签「动作」：只露出第一行「发布到市场」与下一行的一部分（被 280px 裁切，暗示还能往下滚）
- 提示区：「↑↓ 选择 · ↵ 执行 · Esc 关闭」

## 4 视觉规范（钉死）
颜色只用：#0F1115 / #61666B / #81858C / #FFFFFF / #EBEEF2 / #979DA6 / #0000001A / #00000029 / #4176E6 / #22C55E / #F59E0B / #EC1313 / #0000003D；字号只 11 / 12 / 12.5 / 13px，行高 1.5；间距 4/6/8/12/14；圆角 0/8/12；图标 lucide 线性 14px；无阴影无渐变（浮层靠 1px 描边与遮罩区分）。

## 5 状态覆盖
本屏画「空查询 + 分组视图 + 首行高亮」的初始态（`grouped = query.trim() === ''`，渲染顺序 = COMMAND_GROUP_ORDER：前往 → 产物库 → 动作 → 视图 → 处置）。
不要画有输入的关键词过滤态（那时不分组的平铺结果 + 行尾组名）、不要画空态「没有匹配的命令」、不要画禁用项（置灰 + 不可选）。

## 6 保留清单（源码逐个核对）
输入框 `palette.placeholder`「输入命令或搜索…」；分组标签 `palette.group.navigate` 前往 / `palette.group.library` 产物库 / `palette.group.action` 动作 / `palette.group.view` 视图 / `palette.group.rescue` 处置；命令标题取 `nav.home`「首页」、`library.title`「产物库」、`nav.sync`「同步」、`environment.title`「环境」、`library.source.all`「全部」、`library.kind.snapshot`「本机快照」、`library.kind.backupFile`「备份文件」、`library.kind.remote`「远端快照」、`library.kind.market`「市场配置」、`task.title.publish`「发布到市场」；底部提示 `palette.hint`「↑↓ 选择 · ↵ 执行 · Esc 关闭」。

## 7 删除清单
不要标题「命令面板」文字行（源码 Modal title 只做无障碍标签，视觉上只有输入框）；不要 ✕；不要搜索图标或魔法棒图标；不要每条命令的快捷键标注、图标、描述副行；不要滚动条常显；不要左侧栏、品牌块、底部文档终端按钮、渐变、阴影、圆角>16。

## 8 明确禁止
禁止把浮层画成居中的大对话框（宽 420、距顶 80，必须偏上）；禁止九宫格卡片或图标网格；禁止分组标签做成页签；禁止行高忽高忽低（统一 26px）；禁止英文界面；禁止列表撑满整屏。
